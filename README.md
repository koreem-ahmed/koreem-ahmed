# Kareem Ahmed

I'm a STEM October student who builds embedded systems, robotics prototypes, and web tools for student communities. I enjoy taking a project from a schematic and firmware to something people can use.

## Selected projects

| Project | What you'll find |
| --- | --- |
| [Gizmo 2.0](https://github.com/koreem-ahmed/Gizmo-2.0) | An ESP32-S3 desk robot with a custom PCB, microphone, speaker, and servo-driven arms. |
| [Koreem-board](https://github.com/koreem-ahmed/Koreem-board) | A 75% mechanical keyboard with a custom KiCad PCB, two OLED displays, RGB lighting, and a sloped enclosure. |
| [EOCS Certificate Verification](https://github.com/koreem-ahmed/EOCS-Certificates-Verification) | My fork of the Egyptian Olympiad in Computational Science certificate verification portal, built with React, TypeScript, and Vite. |
| [Build Guild Giza](https://github.com/koreem-ahmed/Build-Guild--Giza) | A static event site for the Giza edition of Hack Club Blueprint's hardware meetups. |
| [Charging Station 3000](https://github.com/koreem-ahmed/charging-station-3000) | A custom desk dock for controllers and a headset, with an ESP32-driven display and built-in audio. |
| [Mad Racer](https://github.com/koreem-ahmed/mad-racer) | A retro Godot racing game with four tracks and waypoint-based opponents. |

I also mentor and help organize student programming initiatives through the STEM October Computer Science Club.
